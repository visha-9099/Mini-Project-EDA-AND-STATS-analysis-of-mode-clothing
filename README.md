EDA and Statistical Analysis of Mod Clothing Dataset

This project focuses on exploratory data analysis (EDA) and statistical techniques to clean, analyze, and derive insights from a clothing dataset.

Goals
Apply statistical concepts to real-world problems.
Use EDA and visualization to uncover business insights.
Perform detailed data analysis and hypothesis testing.
Build a comprehensive report to support decision-making.
The project includes theoretical concepts in statistics and hands-on data exploration to extract meaningful patterns for business use.
